# Attribution and distribution

Based on [ed0ard/CS2-Bot-Improver v1.4.10](https://github.com/ed0ard/CS2-Bot-Improver/releases/tag/v1.4.10) and the exact component commits in UPSTREAM-SOURCES.json. Original authors and component licenses remain credited in their source directories.

Maintained source/DLL components: BotAI, BotAimImprover, NadeSystem, BotState, BotStuckDiagnostics, BotVisionCompatibility, BotBuy and BotRandomizer. Corresponding source modifications, tools, policies, tests and bounded logging are included. The original1.4.10/CSS 381 native/API/shared/runtime/implementation dependencies are installed separately. Native DLL adapters from older Fairplay releases are retired; new official native binaries are not modified. Only a narrow gamedata text correction remains. No original panel/frontend assets, VPKs, native/game/runtime/shared DLLs, personal logs/dumps or backups are redistributed.

This is an independent Windows local-match maintenance fork, not an official Valve or upstream release. Keep each component's license/author information when redistributing its source. Source ZIPs contain corresponding source; managed update DLLs are compiled from that source.
