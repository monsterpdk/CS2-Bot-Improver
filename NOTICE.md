# Attribution and distribution scope

This independent update derives from ed0ard/CS2-Bot-Improver v1.4.5, root commit d9914454d8691b509bae4cd671a7a8bd9dcb174f. Release-matching BotAI, BotAimImprover and NadeSystem commits are recorded in UPSTREAM-SOURCES.json. The clean source snapshot does not preserve upstream Git history. Original features belong to their original authors.

The root GNU AGPL v3 text and each included component's existing copyright/license notices are preserved. BotVisionCompatibility, the independent gameinfo wrapper, release tools and tests are supplied as source. The public update includes only four maintained plugin DLL/deps pairs, their map/data files, bot-match cfgs and the wrapper. It does not redistribute the original panel/frontend/assets, runtimes, native/shared binaries, VPKs, stock gameinfo, game binaries, personal logs, dumps or backups. Dependencies are obtained directly from their authors; there are no old Windows gamedata override files in this release.

The v1.4.5 panel uses [PolyForm Strict 1.0.0](https://github.com/ed0ard/CS2-Bot-Improver/blob/v1.4.5/Panel/LICENSE). Its grant excludes distribution and derivative changes. The complete personal-use installer is therefore not a GitHub release asset. The launcher contains no original panel frontend/backend code and starts the separately obtained executable.
